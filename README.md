## 😍 Key Features
- Fast & lightweight validation of [Tiptap](https://github.com/ueberdosis/tiptap) JSON content
- Easy to use API

> [!NOTE]
> This library only validates Tiptap JSON content structure. It does not render or manipulate the content.
